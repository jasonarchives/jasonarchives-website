# Jason Archives [OS]

A brutalist inspired digital archive functioning as my portfolio for UX Research, Experience Design, Photography, and Community Collaboration.

Live deployment: [jasonarchives.online](https://jasonarchives.online)

## Architecture
This environment was built entirely from scratch.

* **Core Stack:** Vanilla HTML5, CSS3, JavaScript (ES6+)
* **Typography:** iA Writer Duospace, SF Pro Display
* **Deployment:** Netlify (Continuous Deployment via GitHub)

## Key Mechanics
* **The Terminal (`/terminal.js`):** A custom-built, keyboard-navigable command line interface invoked via `⌘K`, allowing users to bypass standard navigation and route directly to records using path commands.
* **Cinematic Dossiers:** Horizontal, scroll-linked cinematic layouts built natively for the photography records.

## Local Development
To run this archive locally:
1. Clone the repository: `git clone https://github.com/YOUR_USERNAME/jasonarchives-website.git`
2. Navigate to the directory: `cd jasonarchives-website`
3. Launch a local development server (e.g., using VS Code Live Server or Python's `http.server`).
